# 原理

## 分析方法

对比两个版本的 PCL2：

- 正式版 2.99.0.1 (415)：下载功能被移除。
- 之前可以正常下载的版本（Release 2.6.6）：下载和整合包都正常。

用 `ilspycmd` 把两个程序反编译成 C# 后逐文件对比。除了版本号、更新日志、赞助弹窗和主题代码，和下载有关的差异集中在 `PageDownloadInstall`、`PageDownloadLeft`、`ModModpack`、`PageResource` 四个类里。全工程搜索提示语“为遵守相关法律法规，PCL 不再提供 MC 下载功能”，可以找到所有屏蔽点。

## 屏蔽点和修复

### 1. 原版游戏版本列表

`PageDownloadInstall.LoaderInit` 原本把 `ModDownload.DlClientListLoader` 传给页面加载器。2.99.0.1 换成了一个名为“关闭下载”的新加载器，它只会抛出异常：

```csharp
// 2.99.0.1
PageLoaderInit(LoadMinecraft, PanLoad, PanAllBack, null,
    new LoaderTask<string, DlClientListResult>("关闭下载", _ => throw new Exception("为遵守相关法律法规……")), ...);

// 修复后
PageLoaderInit(LoadMinecraft, PanLoad, PanAllBack, null, ModDownload.DlClientListLoader, ...);
```

`DlClientListLoader` 和它调用的 `DlClientListMain` 在 2.99.0.1 里完整保留。补丁只删掉构造假加载器的那段 IL，换成一条 `ldsfld ModDownload::DlClientListLoader`。

### 2. 下载页左侧栏

`PageDownloadLeft` 构造函数末尾多了四行：

```csharp
ItemInstall.Visibility = Visibility.Collapsed;   // 隐藏“原版游戏”
LabResource.Visibility = Visibility.Collapsed;   // 隐藏“社区资源”标题
PageID = FormMain.PageSubType.DownloadMod;       // 默认页改成 Mod
ItemMod.Checked = true;
```

补丁删掉这四行，界面就回到 XAML 里定义的默认状态。

### 3. 整合包类型分发

`ModModpack.ModpackInstall(File, InstanceName, Logo)` 前半部分仍然会打开压缩包，并识别整合包类型，结果存在局部变量 `num` 里。之前可以正常下载的版本在识别之后按 `num` 调用对应的安装方法。2.99.0.1 把这个 `switch` 换成了 `throw`。

七个 `InstallPack*` 方法都还在，所以补丁按之前可以正常下载的版本的编号重建分发：

| num | 方法 |
| --- | --- |
| 0 | `InstallPackCurseForge` |
| 1 | `InstallPackHMCL` |
| 2 | `InstallPackMMC` |
| 3 | `InstallPackMCBBS` |
| 4 | `InstallPackModrinth` |
| 9 | `InstallPackLauncherPack` |
| 其他 | `InstallPackCompress` |

IL 上的细节：被替换的 `ldstr` 是外层 `catch` 块 `leave` 指令的跳转目标。补丁原地修改这条指令的操作码，没有删掉它，跳转目标就不会失效。每个分支用 `leave` 跳出 `try`，返回值先存进局部变量，在 `finally`（释放 `ZipArchive`）之后再返回。

### 4. 手动导入整合包

无参的 `ModpackInstall()` 被缩减成一句红色提示。但编译器生成的闭包类 `_Closure$__0-0` 和其中的 `_Lambda$__0` 还在。后者负责调用 `ModpackInstall(file)` 并记录错误。

补丁重写这个方法的 IL：

1. 调用 `Dialogs.SelectFile` 让用户选择 `rar` / `zip` / `mrpack` 文件。调用参数的类型引用取自 `ModMinecraft.McSkinSelect`，那里也用了同一个对话框。
2. 如果用户取消，直接返回。
3. 否则创建闭包，填入文件路径，通过 `ModBase.RunInThread` 在后台执行 `_Lambda$__0`。

### 5. “安装已有整合包”按钮

`PageResource` 是 Mod、整合包、资源包等下载页共用的页面。之前可以正常下载的版本在设置页面类型时，只在整合包页显示这个按钮：

```csharp
BtnSearchInstallModPack.Visibility = (value != CompType.ModPack) ? Visibility.Collapsed : Visibility.Visible;
```

2.99.0.1 把比较删掉了，IL 里只剩 `ldarg.1; ldc.i4.2; pop; pop; ldc.i4.2`，结果永远是 `Collapsed`。补丁把这几条换回比较运算。新版的 `ResourceTypes.ModPack` 值为 2：

```
ldarg.1; ldc.i4.2; ceq; ldc.i4.1; xor; ldc.i4.1; shl   // 相等得 0 (Visible)，否则得 2 (Collapsed)
```

## 安全措施

- 每个补丁都先检查特征（例如是否存在“关闭下载”字符串）。已经修过的方法会自动跳过，所以工具可以重复运行。
- 结构和预期不一致时抛出“版本不兼容”，不会强行修改。
- 修改后的程序先写到 `.tmp`，成功后再备份原文件为 `.bak` 并替换。

## 验证

修复后的程序再用 ILSpy 反编译，与原版对比：只有上述五个方法有变化，逻辑都与之前可以正常下载的版本一致。
